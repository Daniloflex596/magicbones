Video Editor Commands Protocol (V19)
This skill dictates how to parse and execute the structured command blocks generated by the user's HTML video editor (V19).

⚠️ CRITICAL RULES
URL IS THE ONLY SOURCE — never substitute a different video. Never guess. 0a. NO GENERATION WITHOUT PERMISSION — always present plan and wait for "go"/"yes"/"generate". Exception: auto_run:on flag means execute automatically. 0b. SHOWING A CORRECTED PROMPT IS FEEDBACK ONLY — never treat it as a generation instruction. 0c. TOOL FAILURE — HARD STOP. If a tool call returns "Result unavailable", empty, or error:
STOP. Do not narrate a successful outcome or fabricate URLs/IDs/data.
Check the artifact store — the result may already be recorded from a prior turn.
If not in artifacts, retry the tool call once.
If retry also fails, tell the user exactly which step failed and why. Never issue a fictional tool result under any circumstances. 0d. SINGLE COHERENT ANSWER — never post two contradictory conclusions in the same message. If you realise mid-draft your initial assessment was wrong, discard the wrong section entirely. The user must receive one clear answer, not a correction appended to a mistake. 0e. STATE RETENTION ACROSS TURNS — when pausing for user confirmation (e.g. "Enhance either frame?"), RETAIN the original command parameters (URLs, duration, prompt, audio flags). When the user replies "skip", proceed immediately using the initial parameters. DO NOT lose state. DO NOT ask the user to provide the command again. Artifact records are canonical state — if prior tool results are missing from context but artifact entries exist, trust the artifacts and re-derive IDs/URLs from them.

RESOLUTION — match Clip 1 via ffprobe. Minimum 720p. Pass as resolution param ("1080p", "720p").

AUDIO MIXING (POST-STITCH)
When adding voiceover, SFX, or music to a stitched video:

Use ffmpeg directly — do NOT pass audio back into a video generation model.
amix: always set normalize=0 to prevent aggressive auto-ducking. ffmpeg -i video.mp4 -i layer.mp3 -filter_complex "[0:a]volume=1.0[va];[1:a]volume=0.55[vb];[va][vb]amix=inputs=2:duration=first:normalize=0[aout]" -map 0:v -map "[aout]" -c:v copy -c:a aac -b:a 192k -ar 44100 output.mp4
Voiceover ducking: use adelay (ms precision) + volume=enable for timed insertion. ffmpeg -i bg.mp4 -i vo.mp3 -filter_complex "[0:a]volume=1.0:enable='lt(t,START)',volume=0.5:enable='gte(t,START)'[bg]; [1:a]adelay=STARTms|STARTms,volume=2.0[vo]; [bg][vo]amix=inputs=2:duration=first:normalize=0[aout]" -map 0:v -map "[aout]" -c:v copy -c:a aac -b:a 192k -ar 44100 output.mp4
Synthesised SFX: when CDN downloads are blocked, use numpy + pedalboard + soundfile. pip install --break-system-packages pedalboard numpy scipy soundfile (FluidSynth/SoundFonts require root — not available).
AUDIO SCORING RULES
When composing scored audio over video with scene changes:

SCENE MARKERS: At each PySceneDetect cut, check if a beat lands within 100ms. If yes, skip the melodic marker (beat already covers it). If no beat within 100ms, place a short melodic non-percussive tone tuned to root key. Never stack melodic on top of beat.
PERCUSSION: Kick/taiko/snare patterns run uniformly. Never accent cuts with percussion.
DIALOGUE DUCK: Music must duck to ~15% under any speech (webrtcvad/silero-vad). Voiceover counts as dialogue. Never let synthesised music compete with voice.
DERIVED RHYTHM: When time_sig:derived, calculate inter-cut intervals from PySceneDetect timestamps. Use shortest gap as base pulse. Map interval ratios to beat groupings.
EXECUTION LIMIT: Individual audio synthesis tasks must not exceed 60s.

Python-Based Audio Splicing & Crossfading (Full-Track Precision): When joining segments (e.g., in a LOOP or BRIDGE with audio:on), ffmpeg's native concatenation or amix/afade filters often cause sync offsets or audio pops on compressed audio boundaries. A bulletproof alternative is to perform sample-accurate full-track audio splicing in Python using soundfile and numpy:

Extract Audio Tracks: Extract audio from individual segment files as uncompressed stereo wav files:
bash

ffmpeg -y -i seg_clipA.mp4 -vn -ac 2 -ar 44100 audio_A.wav
ffmpeg -y -i seg_bridge.mp4 -vn -ac 2 -ar 44100 audio_B.wav
Crossfade and Concatenate in NumPy:
python

import soundfile as sf
import numpy as np

a_data, sr = sf.read('audio_A.wav')
b_data, _ = sf.read('audio_B.wav')

# Standard crossfade duration (e.g., 1.0 second)
fade_len = int(sr * 1.0)
fade_out = np.linspace(1.0, 0.0, fade_len)[:, None]
fade_in = np.linspace(0.0, 1.0, fade_len)[:, None]

# Apply fading on the boundaries
a_data[-fade_len:] *= fade_out
b_data[:fade_len] *= fade_in

# Direct concatenation of the faded tracks
final_audio = np.concatenate([a_data, b_data], axis=0)

# Save the stereo track
sf.write('mixed_final.wav', final_audio, sr)
Mux Back to Concatenated Video: Re-mux the composite audio track into your final concatenated segment video:
bash

ffmpeg -y -i concated.mp4 -i mixed_final.wav -map 0:v -map 1:a -c:v copy -c:a aac -b:a 192k -ar 44100 final_stitch.mp4
