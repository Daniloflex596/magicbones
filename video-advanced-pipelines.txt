Audio Scoring Rules (Cherry Blackcloud)
SCENE CHANGE MARKERS: At every PySceneDetect cut point, check if a beat lands within 100ms of that timestamp. If yes — skip the melodic marker, the beat already acknowledges the cut. If no beat within 100ms — place a short melodic non-percussive tone (e.g. from ffmpeg-audio-synthesis) tuned to the root key. Never stack a melodic marker on top of a beat.
PERCUSSION IS CONSISTENT: Kick/taiko/snare patterns run uniformly across the entire clip. Never accent scene changes with percussion.
VAD AWARENESS (DIALOGUE IS KING): Music must duck to ~15% under any speech (webrtcvad or silero-vad). Never let a synthesised music layer compete with dialogue. Voiceover counts as dialogue.
DERIVED RHYTHM: When time_sig:derived, calculate inter-cut intervals from PySceneDetect timestamps. Use shortest gap as base pulse unit. Map interval ratios to beat groupings. The music is composed from the edit.
AUDIO PACING EXTREMES: Ensure ffmpeg-audio-synthesis steps never breach 60s per individual task execution.

Critical Operating Rules
INTEGRITY & CONTEXT RECOVERY:

NEVER FABRICATE TOOL RESULTS. If a tool call returns "Result unavailable", empty, or error — STOP. Check the artifact store for prior results. If not found, retry the call once. If still failing, report the failure to the user. Never narrate a successful outcome from a failed tool call.
ARTIFACT STORE IS CANONICAL STATE. When prior turn tool results are missing from context (common in long sessions), the artifact entries written at the time of success are the source of truth. Re-derive IDs, URLs, and file paths from artifact records rather than re-running the full pipeline.
ONE ANSWER PER MESSAGE. Never post contradictory conclusions in the same response. If you catch an error mid-draft, discard the wrong section. The user receives one coherent answer.
ENVIRONMENT & EXECUTION PITFALLS:

Math in Terminal: The bc command is not available in the environment. When calculating precise frame trims for FFmpeg (e.g., duration - frame_dur), use Python (python3 -c "print(A - B)") instead of bash arithmetic.
Kling 3.0 Matchcut Element Rejection: Kling 3.0 with end_image (matchcut mode) does NOT support persistent elements (<<<id>>>). If the user includes elements in a matchcut command, explicitly warn them that elements will be dropped due to model incompatibility. Do not silently remove them without notification.
API QUIRKS (SEEDANCE 2.0 & PIPELINE FIXES):

Google Flow Composer Support: After completing a finalized stitch (e.g. video + SFX + voiceover), offer to create a Google Flow Composer audio prompt matched to the video's exact duration and narrative pacing. See references/google-flow-composer.md.
Preview Before Stitch: After generating the AI clip, ALWAYS post the preview URL and ask: "Happy with this? Shall I stitch?" NEVER auto-stitch.
STITCH PIPELINE — REMOVE DUPLICATE FRAMES AND RE-ENCODE: The AI bridge starts on the last frame of the start clip and ends on the first frame of the end clip. Trim these frames before stitching to avoid a stutter. Detect actual framing from Clip 1 fps = ffprobe r_frame_rate and calculate frame span. Clip A (Start): Trim last frame (-ss 0 -to (duration - frametime)). Bridge: Trim first frame (-ss frametime). Clip B (End): Trim first frame (-ss frametime). Always re-encode all segments matching the frame rate (-r), audio (-ar 44100 -af aresample=async=1 -c:a aac), and dimensions of Clip 1. Never concat native clips across unmatched frame rates (e.g. Kling's 30fps and a source 24fps video).
Stitch Order for Loops: Order: original_trim.mp4 -> bridge_trim.mp4.
Aspect Ratio: Auto-detect from Clip 1 via ffprobe.

Audio Mixing & Python Sound Synthesis
Mixing Voiceovers & Audio Files (FFmpeg)
When adding voiceover or external SFX (e.g., WAV/MP3) to an existing video:

Use ffmpeg directly instead of passing the audio back into a video generation model, as models often drop or corrupt secondary audio.
Wait to be told where to position the clip if it wasn't specified.
To delay a voiceover and duck the background track, use adelay and volume=enable:
bash

ffmpeg -y -i video.mp4 -i voiceover.mp3 \
  -filter_complex "
    [0:a]volume=1.0:enable='lt(t,15.667)',volume=0.5:enable='gte(t,15.667)'[bg];
    [1:a]adelay=15667|15667,volume=2.0[vo];
    [bg][vo]amix=inputs=2:duration=first:normalize=0[aout]
  " \
  -map 0:v -map "[aout]" \
  -c:v copy -c:a aac -b:a 192k -ar 44100 \
  output.mp4
Python Sound Synthesis (numpy + pedalboard)
When external SFX downloads are blocked (CDNs like Pixabay/Freesound block headless curl), synthesise the audio directly using numpy and pedalboard. Ensure you install required packages: pip install --break-system-packages pedalboard numpy scipy soundfile. Note: FluidSynth/SoundFonts require root and cannot be used.

Example: Karplus-Strong Pluck (Koto)

python

def karplus_strong(freq, dur_sec, sr, decay=0.996):
    n = int(sr * dur_sec)
    buf_len = int(sr / freq)
    buf = np.random.randn(buf_len) * 0.5
    out = np.zeros(n)
    for i in range(n):
        out[i] = buf[i % buf_len]
        buf[i % buf_len] = decay * 0.5 * (buf[i % buf_len] + buf[(i+1) % buf_len])
    return out
Example: Deep Taiko Kick

python

def make_kick(freq, dur_sec, sr):
    t = np.linspace(0, dur_sec, int(sr * dur_sec))
    sweep = freq * 3 * np.exp(-15 * t) + freq
    phase = 2 * np.pi * np.cumsum(sweep) / sr
    body = np.sin(phase) * np.exp(-8 * t)
    click = np.random.randn(len(t)) * np.exp(-120 * t) * 0.25
    return (body + click).astype(np.float32)

Automated SIFT Matchcut Pipeline
When bridging two visually disparate scenes, use OpenCV SIFT to find a shared visual anchor and construct a camera pass-through prompt.

1. Frame Extraction & SIFT Matching
Extract the end frame of Clip A and start frame of Clip B. Run OpenCV SIFT to find matching keypoints:

python

import cv2, numpy as np
img_a, img_b = cv2.imread('frame_a.jpg'), cv2.imread('frame_b.jpg')
sift = cv2.SIFT_create()
kp_a, des_a = sift.detectAndCompute(cv2.cvtColor(img_a, cv2.COLOR_BGR2GRAY), None)
kp_b, des_b = sift.detectAndCompute(cv2.cvtColor(img_b, cv2.COLOR_BGR2GRAY), None)

matches = cv2.BFMatcher().knnMatch(des_a, des_b, k=2)
good = [m for m, n in matches if m.distance < 0.7 * n.distance]

if len(good) >= 5:
    pts_a = np.array([kp_a[m.queryIdx].pt for m in good])
    anchor_a = pts_a.mean(axis=0) # (x, y)

    y_rel = anchor_a[1] / img_a.shape[0]

2. Prompt Construction
Convert the relative coordinates into a descriptive region (e.g., "upper-left", "center-right"). Construct a prompt directing the camera through this region: "One continuous uncut shot. Camera slowly pushes in toward the [region] of the frame, closing in on the [shared visual element]. At the midpoint the camera is tight on the element. Camera then pulls back wide to reveal the ending composition. Full push-in then full pull-out."

3. Recommended Model
Use Kling 3.0 (kling3_0) with duration: 3 and native start_image and end_image roles. Note: Wan 2.7 does not support hard end_image anchoring. Do NOT pass element tokens (<<<id>>>) as Kling 3.0 with end_image rejects them.Video Pipeline Prompting & Limits
Prompt Standards
Anchor Tokens: Always start with @Image1 MUST be the first frame. and end with @Image2 MUST be the final frame. (or start_image/end_image equivalents based on the model).
Positive Language: Always use positive phrasing. Examples: speechless, musicless, uncut, transitionless, continuous. NEVER use negative phrasing when a positive form exists (e.g., avoid "no cuts"). NEVER use transition words like dissolve, fade, morph, blend, or wipe — describe what the subject physically does instead.
Chronological Narrative: Describe what is visible in the start frame, what the camera does through the middle, and what the end frame shows. Guide the model chronologically based on the visible frames.
Inline Elements: Embed <<<element_id>>> immediately after the character's name in the narrative description. Never list elements at the end as "Characters present:". Introduce them contextually (e.g., "The faceless Noppera-bō <<>> leads...").
Canon Details: Weave confirmed lore and character traits into the prompt implicitly.
Audio Directives: End with Speechless, musicless, ambient sound only. If the source has music: Speechless, ambient sound only, continue source music seamlessly.
Reference Slot Limits
Models have strict limits on total media references (medias array + input_audio + prompt <<<element_id>>> tokens).

Seedance 2.0: MAX 9 reference slots total. If using Start Frame, End Frame, Audio 1, and Audio 2 (4 fixed slots), you have a MAX of 5 element tokens allowed in the prompt.
Kling 3.0: Fewer slots. Safe maximum is 3 elements. Note: Kling 3.0 is incompatible with elements when end_image is used. Do NOT pass elements when doing matchcuts with Kling 3.0. Warn the user if they request too many.
NSFW Fallback Strategy
If an element or generation triggers an NSFW string/filter:

Do not remove all elements at once.
Remove the LAST element token from the prompt and retry.
If it passes, the removed element was the culprit (e.g., due to reference images violating safety limits, such as @MsYurei). Inform the user.
If still NSFW, remove the next last element and retry.
Proceed one by one to isolate the issue.Seedance 2.0 API Quirks & Limits
1. Dimensionality requires aspect_ratio Seedance 2.0 entirely ignores the width and height parameters. If you do not specify an explicit aspect_ratio (e.g., aspect_ratio: "21:9" or "16:9"), the video will default to a 1:1 square, regardless of the input frame dimensions.

2. Audio Input (500 Internal Server Error) Do NOT pass audio in the medias array using role: "audio". This will result in an immediate HTTP 500 error from the Seedance 2.0 endpoint. You must pass audio via the top-level input_audio parameter inside params:

  "input_audio": {"id": "<uuid>", "type": "media_input", "url": "..."}
